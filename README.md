
# 🧮 Python Calculator

A simple and beginner-friendly calculator built using Python. This project is designed to practice Python programming fundamentals and implement basic calculator functionality.

## ✨ Features

- Easy-to-understand Python code
- Simple calculator implementation
- Lightweight and beginner-friendly
- Runs directly from the terminal

## 🛠️ Technologies Used

- **Language:** Python 3
- **Editor:** Visual Studio Code

## 🚀 Getting Started

### Prerequisites

Install Python 3 on your system.

Check your Python installation:

```bash
python --version
```

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/puneet-a11/calculator.git
   ```

2. Open the project folder:

   ```bash
   cd calculator
   ```

3. Run the calculator:

   ```bash
   python calculator.py
   ```
